# EventManagement

A full-stack web application for managing events, including event creation, registration, and user management. This project consists of a **frontend** built with **React.js** and **Tailwind CSS**, and a **backend** built with **Node.js** and **Express.js**.

---

## 🗂 Project Structure

EventManagement/
├─ frontend/ # React.js + Tailwind CSS frontend
├─ backend/ # Node.js + Express.js backend
├─ README.md

---

## ⚡ Features

- **Event Creation**: Admin can create, update, and delete events.
- **Event Registration**: Users can register for events.
- **User Management**: Admin can manage user registrations and details.
- **Responsive Design**: Works smoothly on desktop and mobile devices.
- **API Integration**: Frontend communicates with backend REST APIs.

## 🚀 Getting Started

### 1️⃣ Clone the Repository


2️⃣ Setup Backend
cd backend
npm install
npm start


Runs backend server on http://localhost:5000 (default port)

Make sure to configure your database in .env

3️⃣ Setup Frontend
cd ../frontend
npm install
npm start


Runs frontend on http://localhost:3000

Automatically opens in browser
